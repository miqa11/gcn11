# Darker appearance and private-chat activities

Choose **შუაღამე · უფრო მუქი** in private-chat settings (🎨) or random chat's background picker. The device-local preference darkens chat surfaces and message bubbles. It persists when returning to chat and synchronizes between chat tabs on the same device. Selecting standard restores the original chat appearance.

Private chat now has **მუსიკა** and **თამაშები** controls. Both friends must open that same conversation. These reuse `music.js` / `games.js` and their existing invite/player/game interfaces: Tic Tac Toe, Rock Paper Scissors and Math Duel. A private-page adapter translates only activity events to `friendActivity:*`; private text/encryption events keep their existing raw socket and protocol. The server never assigns or borrows random-chat `socket.partner` pointers. A separate random-chat tab stays independent.

The private server module validates mutual friendship, block status, current conversation and exact invited socket on acceptance. It owns pending invitations, game turns/results and the accepted music video. Pending invitations expire after 30 seconds; fabricated or mismatched acceptance cannot start an activity. Math answers and RPS choices stay server-side until results. Music controls are finite/bounded, sent only within the accepted session. Closing a game, leaving the page, switching conversations or disconnecting cleans relevant sessions. Presence is indexed per conversation rather than scanning unrelated chats.

Theme choice sends no shared-wallpaper update and makes no server charge. Private music uses the existing YouTube search/player connection; video availability and browser autoplay limits still apply. The existing tap-to-play fallback is retained. Activities are session-only; reconnecting enables new invitations when both pages are present again, rather than resuming an unfinished game.

Validation: seven server tests cover private routing without random-partner mutation, mutual friends, integer/turn enforcement, invitation expiry/forgery, music selection/control isolation, context switching, disconnect and blocking. Two theme tests cover persistence, default reset, storage failure and chat-only asset loading. The full suite passes 122 tests. The optional browser fixture `node scripts/check-private-chat-activities.cjs` checks existing private text messages, all three games, music start/pause/stop, theme selection/navigation/reset/peer isolation, random-chat selection and portrait/landscape fit. Use the Playwright setup and `CITY_QA_CHROME` described in [city-mobile-layout.md](city-mobile-layout.md). The fixture uses controlled accounts/search/YouTube-player responses; it does not prove live YouTube playback or real-device autoplay behavior.
